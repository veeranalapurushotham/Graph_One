1. Startups — 1,000+ verified rows
2. Products — 1,000+ verified rows
3. Research Papers — 1,000+ verified rows with GitHub stars
4. Jobs — all verified jobs published within 24 hours
5. News — all verified news published within 24 hours

Do not commit fabricated rows. Generate outputs from live crawls, preserve source URLs, validate freshness, then export/upload the verified result to Google Sheets.
