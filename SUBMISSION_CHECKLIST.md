# Final Submission Checklist

Use this checklist immediately before submitting the AI Engineer task.

- [ ] 1,000+ verified startup records
- [ ] 1,000+ verified product records
- [ ] 1,000+ verified research-paper records
- [ ] Five required AI news sources crawled
- [ ] Five required AI job sources crawled
- [ ] News/jobs restricted to the required 24-hour window
- [ ] Full text and source URL retained for news/jobs
- [ ] GitHub URLs/stars enriched where required
- [ ] Gemini Flash → Groq Llama 3 → DeepSeek fallback tested with real API responses
- [ ] 413 chunking tested
- [ ] 429 Retry-After/backoff/jitter tested
- [ ] Entity resolution output and logs generated
- [ ] Async crawler and Playwright escalation tested
- [ ] Raw/provenance data retained
- [ ] End-to-end pipeline run completed successfully
- [ ] Tests pass
- [ ] Final Google Sheet created and verified
- [x] Architecture PDF committed at `docs/architecture.pdf`
- [x] README and architecture documentation committed

## Important
Never replace missing records with invented or synthetic records. If a source cannot be accessed legally or reliably, record the limitation and use an allowed API/feed or mark the source unavailable.

## Submission gate
Submit only after every unchecked item above has been verified with actual evidence.
